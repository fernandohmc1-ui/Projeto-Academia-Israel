
# Site para Academia

## Sobre o projeto
Desenvolvimento de um site para academia utilizando HTML, CSS e JavaScript.

O objetivo é apresentar informações sobre a academia, seus planos, modalidades, exercícios físicos e treinos, proporcionando aos usuários uma consulta simples e organizada dos serviços oferecidos.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

## Funcionalidades previstas
- Página inicial
- Cadastro de alunos
- Consulta de planos
- Modalidades disponíveis
- Apresentação de treinos
- Horários das atividades
- Informações sobre a academia e contato
